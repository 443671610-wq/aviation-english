🗣️ 实际通话场景 Scenario Dialogues

Practical Communication Examples

📡 应答机编码设置 Transponder Code Setting

管制员:

CCA1234, Beijing Approach, squawk 4567.

国航幺两三四，北京进近，应答机四五六七。

飞行员:

Squawking 4567, CCA1234.

应答机四五六七，国航幺两三四。

管制员:

CCA1234, identified.

国航幺两三四，已识别。

🆘 紧急应答机编码 Emergency Squawk Code

飞行员:

Mayday, Mayday, Mayday, Beijing Control, CCA1234, we have engine fire, request immediate descent to FL150.

求救，求救，求救，北京区域，国航幺两三四，我们发动机起火，请求立即下降到高度幺五洞洞。

管制员:

CCA1234, Beijing Control, roger Mayday. Squawk 7700. Descend to FL150, turn right direct to BEKOL.

国航幺两三四，北京区域，收到求救。应答机七七洞洞。下降到高度幺五洞洞，右转直飞BEKOL。

飞行员:

Squawking 7700, descending to FL150, turning right to BEKOL, CCA1234.

应答机七七洞洞，下降到高度幺五洞洞，右转至BEKOL，国航幺两三四。
